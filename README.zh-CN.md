# World Players

**像玩家一样会穿装备、会打架的居民。**

这是一个 Minecraft **1.21.1** / **NeoForge** 模组：用玩家模型做的居民，拥有玩家式背包、装备、经验修补、
寻路与完整战斗系统；0.3.0 起还能划工作区、按日程过日子，有心情、体力与饥饿；0.3.1 起更能走
**玩家手画的路径网**，不用再陪着上楼下楼。

> **状态：v0.3.1**（2026-11-28）。可以正常玩，仍在继续开发。
> 精确数值见 [docs/MECHANICS.zh-CN.md](docs/MECHANICS.zh-CN.md)，版本记录见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

### 居民
- 玩家模型 **4 种形态**（宽 / 细 / 儿童宽 / 儿童细）；儿童能从 1 格缝隙钻过。
- **10 % 概率左撇子**；自带皮肤池、自定义皮肤、**按 Mojang ID 下载正版皮肤**、可改名。
- 玩家式 **41 槽背包**（主手、快捷栏、主背包、4 盔甲、副手），有自己的 GUI。
- 装备会掉耐久、**经验修补**、不死图腾、吸取经验。
- 用**居民刷怪蛋**召唤；死亡会在聊天栏播报，绑定过床的 5 秒后在床边复活。

### 居民手册
- 右键打开笔记本风格的手册页面；对居民**左键切换 跟随 / 站立 / 自由活动**。
- 可开关**状态浮窗**（名字 / 情绪 / 当前工作），侧边栏顺序可编辑。

### 三种模式
- **跟随** — 狗式跟随，被落下会安全传送到你身边；能帮你插火把（不合成）。
- **站立** — 钉在原地，免疫击退，照常战斗。
- **自由活动** — 交给他自己的日程（工作 / 自由时间 / 睡觉）。

### 工作区（0.3.0）
- 用手册规划区域（64 格射线、六面滚轮、白蒙、颜色 / 可见性）：**道路、挖掘、填充、农田、树场、
  牧场、渔场、娱乐、禁行、自订** 共 10 种，带清单页 / 详情页 / 滚动。
- 每个区域最多 **5 名员工**（渔场 **1 名**）；后选的区域会把员工从别的区域抢过来。

| 类型 | 居民会做什么 |
|---|---|
| **农田** | 采收成熟作物、把泥土耕成耕地、播种。**兼容 Farmer's Delight：水稻以外的作物也能种，所有作物都能收。** |
| **树场** | 扫描「区域 + 上方 40 格」，**不走过去**直接砍完整棵树（连树叶），自动补种树苗，支持 2×2 大树。 |
| **挖掘 / 填充** | BFS 队列 + 区域外站位，检查工具 / 方块，完工放烟花。 |
| **牧场** | 选动物类型（牛 / 绵羊 / 猪 / 鸡）、数量上限 2~64、剪毛开关；剪毛 → 繁殖 → 屠宰循环，掉落进背包，自动换最好的武器。 |
| **渔场** | 区域只标站位；在 4.5 格内找水、抛竿、等咬钩、按原版钓鱼战利品结算（饵钓 / 海之眷顾生效），每次抛竿前重新验水。 |
| **娱乐** | 500 字简介；居民自由时间去那里恢复心情。 |
| **禁行** | 居民不会主动进入；已经在里面的会自己走出来。 |
| **自订** | 0.3.1 新增：没有固定工作的白纸区域。派员工进去后按区域名通勤、在区域里游荡（只有一格可站就站住），详情页可填「工作状态：」文字，员工工作时头顶显示这段字、每次输入即保存。 |

### 路径网（0.3.1）
- 用**路径笔**画路线：左键在 路径点 → 锚点 → 删除 之间循环，右键先选一个点再点另一个点连线，
  Alt + 滚轮改动作（走 / 跳 / 爬梯 / 传送）。手拿路径笔时 32 格内的点和段穿透方块显示。
- 居民会挑最近的同层锚点、按段跑 Dijkstra 自己走完路线——只要每个锚点都走得到，就不必再陪着上楼下楼。
- 段默认是**单轨共用通道**：居民先预约再走，走不了就**排队等**、不会正面相撞；等满 5 秒有死锁兜底传送。
  闲逛会避开路网，所以没人堵在楼梯间。

### 生活系统（0.3.0）
- **日程**：工作（10 分钟）→ 自由时间（有工作 10 分钟 / 没工作 20 分钟）→ 游荡 → 去最近的娱乐区 →
  回床睡觉。跟随 / 站立 / 翻背包会冻结全部计时；跟随 / 站立还会**暂停睡觉**（人起床、体力不扣，
  解除后接着睡剩下的部分）。
- **心情与体力**：随时间衰减，影响干活节奏与移速；两者都 >75 % 时工作效率翻倍。
- **饥饿**：会从背包里找吃的，会给饿肚子的邻居分食物，**拒吃生肉**。
- **床**：绑定床，**睡到体力满 100 %** 才醒并加心情；没有床的居民显示「（流浪）」。

### 战斗
- 只攻击**真正看得见**的敌对生物；32 格内任何居民或玩家被攻击都会去援助；追不到的敌人会放弃。
- **自动挑背包里最好的盔甲、伤害最高的武器（更偏爱剑）**；**自动在近战和远程之间切换**；
  弓手 / 弩手会自己找射击位；空闲时自动给弩上弦。
- **盾牌**：战斗中举起，挡正面 **270°**，会掉耐久，被斧头砍中禁用 5 秒。
- 武器 / 盔甲 / 盾牌都消耗耐久、附魔生效；经验能修补经验修补装备。
- 永远不攻击玩家、铁傀儡和其他居民；中立生物只在被攻击时还手。
- 近战扫击半伤害 + 音效粒子，攻击冷却按原版攻速走。

### 移动与安全
- 不走进危险方块（岩浆、火、岩浆块、仙人掌、甜浆果、蜘蛛网、细雪），不会主动跳下会摔伤的高度，
  被环境伤害后自动挪开。
- 寻路理解门和栅栏门（只有该区域的员工能开关它的门）、道路更省、禁行区不可进、落脚点必须能站。

### 语言
- 简体中文、英文。

## 构建

```bash
# Windows，Java 21
set JAVA_HOME=C:\Program Files\Java\jdk-21.0.10
set GRADLE_USER_HOME=C:\wp-gradle-home
gradlew.bat build
```

产物在 `build/libs/`。

> Windows 上如果项目路径含非 ASCII 字符，`gradlew.bat` 会因为 cmd 用旧代码页解析 classpath 而失败。
> 先把项目映射到 ASCII 盘符：`subst W: "<项目目录>"` → 在 `W:\WorldPlayers` 里构建 → `subst W: /D`。
>
> `libs/` 里放的是仅编译期使用的 API jar（Jade、3D Skin Layers、Chat Heads、JECharacters、PinIn），
> 不进 git；构建前先放好，或删掉 `build.gradle` 里对应的 `compileOnly` 行。
