# 机制与精确数值

下面写的是 **0.3.0** 实际发出去的行为，数值取自代码（`com.worldplayers`），除特别说明都按「每名居民」计。
有疑问时以代码为准。

## 生存数值

### 体力
| | |
|---|---|
| 自然衰减 | 清醒时每 **4 分钟 −1 %**（站岗、睡觉不扣） |
| 睡觉恢复 | **0.3 %/秒**，到 **100 %** 才醒 |
| 累瘫 | **≤ 10 %** 时自己回床 |

### 心情
| | |
|---|---|
| 自然衰减 | 清醒时每 **30 秒 −1 %**；游荡时**减半**；站岗、睡觉**不扣** |
| 娱乐区 | 每 **10 秒 +0.5 %** |
| 社交（对视） | 每次 **+2 %**，**40 秒**冷却 |
| 分享食物 | **+5 %**（双方），冷却 5 秒 |
| 自然醒 | **+28 ~ 32 %** |
| 移速 | 绿 / 黄 / 红三档 |

### 饥饿
| | |
|---|---|
| 满条 | **100 % = 20 点** |
| 走路 | 每格 **0.05625** |
| 劳动 | 每秒 **0.09375** |
| 生肉 | **拒吃**（原版生肉 + `#c:foods/raw_meat` / `#c:raw_meats` / `#worldplayers:raw_meat`） |
| 食物分级 | 普通食物优先，农作物垫底；辣椒黑名单 |

## 劳动节奏

两次劳动之间的冷却取**心情与体力中较低**的那一项（饥饿也会拖慢）：

| 心情 & 体力 | 冷却 |
|---|---|
| ≥ 75 % | **20 tick** |
| ≥ 50 % | **40 tick** |
| < 50 % | **60 tick** |

- **双倍效率**：心情 **> 75 %** 且体力 **> 75 %** 时，体力消耗与工具耐久消耗**减半**。

## 日程

| 阶段 | 时长 | 说明 |
|---|---|---|
| `WORK` | **10 分钟** | 只有走进工作区才计时；跟随 / 站立 / 翻背包 / 调试棒冻结全部计时；战斗与社交只暂停工作计时 |
| `FREE` | **10 分钟**（有工作）/ **20 分钟**（无业） | 先游荡 **1 分钟**，若剩余 **≥ 6 分钟** 就去 **128 格**内最近的娱乐区（通勤不计时） |
| 娱乐 | **5 分钟** | 计入 `FREE`，结束回去继续游荡 |
| `SLEEP` | 睡到体力 **100 %** | 回床；没有床就不进休息阶段 |

- 空闲时被指派工作，**2 秒内**切到 `WORK`。
- 娱乐计划超过 **3 分钟**没结束会自动兜底。
- 自由时间结束后，同优先级的闲逛 / 娱乐会让位给工作。

## 工作区

| | |
|---|---|
| 区域规划 | **64 格**射线、六面、滚轮缩放 |
| 员工栏 | 每区域 **5 个**，渔场 **1 个**；后选区域会把员工抢过来 |
| 工作距离 | **4.5 格**（农田、树场） |
| 「在区域里」 | 按脚所在方块 / 脚下一格的方块坐标判定（不是浮点包围盒） |
| 类型 | 道路、挖掘、填充、农田、树场、牧场、渔场、娱乐、禁行 |

### 农田
- 采收成熟作物、把泥土耕成耕地（工具 −1 耐久）、补种。
- 每次劳动 **−0.1 体力**；扫描节流 **20 ~ 40 tick**。
- 认 `CropBlock` / `StemBlock`，所以 Farmer's Delight 的作物（含水稻）都能种 / 收。

### 树场
- 扫描「区域 **+ 上方 40 格**」；槽位 / 违规树苗只算区域内。
- **外扩 3 格**只用于站位（外圈只站人，不砍）。
- 只认 `*_log`；切比雪夫间距 **≥ 2**（2×2 豁免）；从 **6 个候选**里挑最近的未占用树。
- **原木 12 tick 一格**（双倍时 6）、**树叶 5 tick**，树叶不耗体力。
- **不走过去**直接无限触及砍完整棵树；砍不到的树进黑名单 **60 秒**。
- 2×2 大树补 **4 个树苗**。

### 挖掘 / 填充
- BFS 队列，先到先领；站位在区域外。
- 缺工具 / 缺方块会停下喊话（**30 秒**冷却）。
- 完工删区域 + 放烟花 + 聊天播报。

### 牧场
| | |
|---|---|
| 动物上限 | **2 ~ 64** |
| 剪毛 | 每 **60 秒**一次；需要剪刀，没有就喊话跳过 |
| 繁殖 | 每 **6 分钟**；一次挥臂喂 **3 格**内所有未冷却的成年动物 |
| 屠宰 | 数量 **大于**上限才杀；优先成年、优先冷却中的；**3 格**内 |
| 屠宰锁 | 区域级 **1 秒**（防止两个员工同 tick 各杀一只） |
| 重置 | 区域内没人 **3 秒**就重置循环 |

### 渔场
| | |
|---|---|
| 区域 | 只标站位（方块 + 上面一格，无碰撞） |
| 找水 | 站位 **4.5 格**内的任意水方块，逐格验视线 |
| 咬钩 | **100 ~ 600 tick**，**饵钓每级 −100** |
| 战利品 | 原版 `minecraft:fishing` 战利品表，海之眷顾生效 |
| 水干了 | **60 秒**后重试 |
| 找竿 | 每 **20 tick** 翻一次背包；副手有竿也算 |
| 每次抛竿 | **−0.1 体力**、**−1 耐久** |

## 战斗

| | |
|---|---|
| 援助半径 | **32 格** |
| 放弃追击 | 大约 **8 秒**摸不到敌人 |
| 近战扫击 | **半伤害** + 音效 + 粒子 |
| 攻击冷却 | 原版攻速 |
| 盾牌 | 挡正面 **270°**，会掉耐久，被斧头砍中禁用 **5 秒** |
| 经验修补 | **1 点经验 = 2 点耐久** |
| 永不攻击 | 玩家、铁傀儡、其他居民 |
| 中立生物 | 只在被攻击时还手 |

- 挑武器：最好的盔甲 + 伤害最高的武器，更偏爱剑。
- 屠宰：`#c:tools/knife` 压倒优先（记 1000 分），其次攻击力最高；每 20 tick 检查一次。

## 社交

- 每 **10 秒**检查一次谁缺饭；社交冷却 **5 秒**。
- 给饭的一方至少要有 **2 份**食物。
- 对视 **40 tick**，然后双方挥手。
- 每 **8 份**食物转 **1 份**，封顶 **16 份**；双方各 **+5 %** 心情。
- 娱乐中不会主动发起分享（但仍可能被叫走）。

## 床、睡觉、复活

| | |
|---|---|
| 睡觉 | 睡到体力 **100 %** |
| 自然醒 | **+28 ~ 32** 心情 |
| 被打断 | **30 秒**续睡窗口，超时放弃、**60 秒**后重试 |
| 睡觉时切跟随 / 站立 | 睡眠被**暂停**（起床、体力停在原处）；取消后回床接着睡 |
| 复活 | 绑定床的 **5 秒**后复活，满血满饥饿，体力心情保留 |
| 床高亮 | 手持手册时高亮玩家周围 **32 格** |
